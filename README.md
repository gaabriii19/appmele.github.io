# Liga de Petanca Invernal del CDPT

Clasificaciones y resultados de los grupos 1, 2 y 3 (temporada 2026/27).

## Publicar en GitHub Pages
1. Crea un repositorio y sube `index.html`, `data.json` y este `README.md`.
2. En **Settings > Pages**, elige la rama `main` y la carpeta `/ (root)`.
3. La web quedará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Actualizar resultados (administrador)
1. Abre la web añadiendo `#admin` al final de la dirección.
2. Escribe los resultados en la pestaña Jornadas (se guardan como borrador en tu navegador).
3. En la pestaña Datos pulsa **Descargar data.json**.
4. Sustituye `data.json` en el repositorio por el descargado (Add file > Upload files).

Los participantes abren la dirección normal y ven los datos en solo lectura.
